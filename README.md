# مملكة الدمج

لعبة دمج وبناء مبنية بـ Phaser 3، تشتغل على المتصفح.

## التشغيل

افتح `index.html` بالمتصفح. ما تحتاج تثبيت، Phaser بيتحمّل من CDN.

## شو فيها

### المراحل (الحرب العالمية الأولى)
- كل مرحلة فيها **دقيقة** لبناء المطلوب.
- المطلوب دايماً: **برج قنص** و**معسكر تدريب** (دفاعات)، + **مبنى جديد** مختلف لكل مرحلة (أكياس رمل، أسلاك شائكة، عش رشاش، مدفعية، خندق، مستشفى ميداني، مصيدة دبابات، مخبأ القيادة).
- البناء بالدمج: كل خشبة بتعطي نقاط (حطب ١، خشب ٣، لوح ٩). اسحبها وافلتها على بطاقة المبنى.
- إذا خلّصت البناء قبل الدقيقة، الهجوم بيبدأ فوراً.
- إذا الدقيقة خلصت:
  - **البناء ٨٠٪ أو أكثر:** الدفاع يصمد، وتنفتح المرحلة الجاية وتاخد ذهب.
  - **أقل من ٨٠٪:** الهجوم ينتصر، وتعيد المرحلة من البداية.
- المرحلة الجاية ما تنفتح إلا إذا خلّصت اللي قبلها.

### المعركة
مشهد هجوم بالأسلوب العسكري: خنادق، أكياس رمل، رصاص رشاش، قذائف مدفعية، ودخان. النتيجة بتتحدد حسب نسبة البناء.

### شي ثاني
- **صندوق اليوم:** مرة باليوم، والسلسلة المتواصلة بتزيد المكافأة لحد 7 أيام.
- **القصر:** ٤ أجزاء بالترتيب (أساس ← أسوار ← برج ← سقف)، بتكلّف ذهب.
- **صوت واهتزاز:** إذا المتصفح يدعمهم.

## الحفظ

التقدم بيتحفظ بـ localStorage على نفس الجهاز والمتصفح.

## الخطوات الجاية

- خريطة مناطق أوسع وأحداث أسبوعية.
- Capacitor لتحويل اللعبة لأندرويد.
