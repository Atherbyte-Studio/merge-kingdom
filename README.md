# مملكة الدمج

لعبة دمج مبنية بـ Phaser 3.

## التشغيل

افتح `index.html` بالمتصفح. لا تحتاج تثبيت أي شي، Phaser بيتحمّل من CDN.

## المرحلة 1 (الحالية)

- شبكة 6×6.
- سحب وإفلات: نقل لخانة فاضية، أو دمج عنصرين من نفس المستوى.
- المستويات: حطب ← خشب ← لوح.
- زر `+ حطب` يضيف حطبة بخانة عشوائية فاضية.
- التقدم بيتحفظ بـ localStorage.

## الخطوات الجاية

- المرحلة 2: الطلبات من القرية، والصندوق اليومي.
- المرحلة 3: أجزاء القصر.
- المرحلة 4: الغزوات والدفاع.
- Capacitor لتحويل اللعبة لأندرويد.
