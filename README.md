# مملكة الدمج

لعبة دمج وبناء مبنية بـ Phaser 3، تشتغل على المتصفح.

## التشغيل

افتح `index.html` بالمتصفح. ما تحتاج تثبيت، Phaser بيتحمّل من CDN.

## المراحل

- ١٠ مراحل متسلسلة. أول مرحلة مفتوحة، وكل مرحلة بتفتح اللي بعدها لما تنتهيها.
- كل مرحلة فيها دقيقة لتجهيز المواد للعمال.
- المطلوب دايماً: **برج قنص** و**معسكر تدريب** (دفاعات)، + **مبنى جديد** لكل مرحلة (أكياس رمل، أسلاك شائكة، عش رشاش، مدفعية، خندق، مستشفى ميداني، مصيدة دبابات، مخبأ القيادة، محطة لاسلكي، مخزن ذخيرة).
- **المواد:** خشب، حجر، حديد. كل مادة لها ٣ مستويات (حطب ← خشب ← لوح، حصى ← حجر ← كتل، خردة ← قضبان ← صفائح).
- **البناء:** اسحب المادة على بطاقة المبنى. لما تكتمل مواده، العمال بيبدأوا البناء (بوقت محدد)، والبطاقة بتعرض تقدمهم.
- إذا خلّصت كل المباني قبل الدقيقة، الهجوم بيبدأ فوراً.
- إذا الدقيقة خلصت:
  - **البناء ٨٠٪ أو أكثر:** الدفاع يصمد، وتاخد ذهب وتنفتح المرحلة الجاية.
  - **أقل من ٨٠٪:** الهجوم ينتصر، وتعيد المرحلة من البداية.

## المعركة
مشهد هجوم بالأسلوب العسكري: خنادق، أكياس رمل، رصاص رشاش، قذائف مدفعية، ودخان.

## شي ثاني
- **صندوق اليوم:** مرة باليوم، والسلسلة المتواصلة بتزيد المكافأة لحد 7 أيام.
- **المدينة:** ١٠ مباني تُبنى على مدار ٣٠ يوم حقيقي. عامل واحد يبني بالتسلسل، والوقت بيكمل حتى لو سكّرت اللعبة.
- **إيقاف مؤقت:** يوقف وقت المرحلة والبناء، وتقدر تكمّل أو تعيد المرحلة أو ترجع للمراحل.
- **صوت واهتزاز:** إذا المتصفح يدعمهم.

## الحفظ
التقدم بيتحفظ بـ localStorage على نفس الجهاز والمتصفح.

## الخطوات الجاية
- خريطة مناطق أوسع وأحداث أسبوعية.
- Capacitor لتحويل اللعبة لأندرويد.
