# مملكة الدمج

لعبة دمج وبناء مبنية بـ Phaser 3، تشتغل على المتصفح، وجاهزة للتحويل لأندرويد.

## التشغيل

افتح `index.html` بالمتصفح. لا تحتاج تثبيت، Phaser بيتحمّل من CDN.

## شو فيها

- **الدمج:** شبكة 6×6، حطب ← خشب ← لوح. تسحب وتدمج، أو تنقل لخانة فاضية.
- **قرية الطلبات:** تسحب الشي المطلوب وتفلته على بطاقة الطلب. كل طلب بيعطي ذهب.
- **صندوق اليوم:** مرة باليوم، والسلسلة المتواصلة بتزيد المكافأة لحد 7 أيام.
- **القصر:** ٤ أجزاء بالترتيب: أساس ← أسوار ← برج ← سقف، كل جزء بيكلّف ذهب.
- **الغزوات:** بعد بناء الأسوار، كل ٤ ساعات بتجي غزوة. لازم تدفع خشب للأسوار خلال ساعة، وإلا بتخسر ذهب. كل ما تصدّ غزوات، بتزيد الصعوبة.

## الحفظ

التقدم بيتحفظ بـ localStorage على نفس الجهاز والمتصفح.

## الخطوات الجاية

- خريطة فيها مناطق تنفتح كل أسبوع.
- أحداث أسبوعية وجوائز حصرية.
- وحوش بالضباب.
- Capacitor لتحويل اللعبة لأندرويد.
